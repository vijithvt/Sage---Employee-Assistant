# IT Helpdesk — Standard Operating Procedure

## Support Hours
The IT helpdesk is available Monday through Friday, 9:00 AM to 5:00 PM local
time, excluding public holidays. Outside these hours, urgent issues affecting
production systems can be escalated via the on-call pager.

## How to Submit a Ticket
Employees should submit support requests through the IT portal at
helpdesk.company.internal or by emailing it-support@company.internal. Please
include a clear description of the issue, the device or system affected, and
any error messages received. Phone and walk-up requests are logged as
tickets retroactively to ensure proper tracking.

## Priority Levels and Response Times
- **Critical** (production system down, security incident): response within
  30 minutes.
- **High** (major functionality broken, single employee blocked from work):
  response within 4 business hours.
- **Medium** (minor functionality issue, workaround available): response
  within 1 business day.
- **Low** (general questions, feature requests): response within 3 business
  days.

## Password Resets
Employees can reset their own password via the self-service portal using
multi-factor authentication. If self-service is unavailable, contact the
helpdesk with your employee ID for identity verification before a manual
reset is performed.

## New Equipment Requests
Requests for new laptops, monitors, or peripherals must be submitted through
the IT portal with manager approval. Standard equipment is typically
delivered within 5 business days; non-standard requests may take longer and
require additional budget approval.

## Software Installation
Only software approved on the company's software catalog may be installed on
company devices. Requests for new software must go through IT for a security
and licensing review before installation.
